# Employee Performance & HR Analytics Dashboard

---

## Overview
This project analyzes **employee performance, attendance, and satisfaction** across departments to identify productivity drivers and improvement areas. Key insights include:
- **Strong correlation** between attendance (92%) and performance (R² = 0.97).
- **IT Department** leads with a 9.4/10 performance score due to extensive training.
- **Developers earn 28% more** than the company average, requiring salary benchmarking.

---

## Features
✅ **Interactive Dashboard**: Slicers for Department, Role, and Tenure.  
✅ **Advanced Formulas**: `CORREL`, `AVERAGEIFS`, `DATEDIF`.  
✅ **Charts**: Scatter plots, bar charts, line charts.  
✅ **Automated Reports**: Dynamic KPIs and trend analysis.

---

## Dataset
- **Columns**: `Employee ID`, `Department`, `Role`, `Tenure`, `Attendance (%)`, `Performance Score`, `Salary`, `Training Hours`, `Satisfaction Score`.
- **Rows**: 50+ mock employee records (2020–2023).  
- **Source**: [Download CSV](data/employee_performance_data.csv).
